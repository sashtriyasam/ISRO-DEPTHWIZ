# /team:handoff

Write a workstream handoff another agent or teammate can consume.
Respect `AGENTS.md`.

Include: branch, base commit, what changed (files + why), tests run +
results, Project item / issue numbers touched and their new status
(with evidence), open blockers with owner, exact next step, and
anything that must NOT be assumed (unverified claims, unmerged
dependencies). Keep it factual — no completion language without
evidence.
